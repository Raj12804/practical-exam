# practical-exam
The uploaded file is a simple registration form that checks validity of each field. 

The user should meet the correct requirements while filling the form.

For incorrect format a warning in red is shown and when correctly filled gives validation in green.

----------Deployment Instructions------------

1.Create the web application consisting the files such as .html, .css and .js file.

2.Open Github create a new repository (any name), and choose its visibility as public.

3.Once the repository is created, upload the web application in the repository.

4.Oce the files are uploaded, go the to the repository setting, under setting go to pages section, select deploy from branch for build and deployment and select main and root in branch section and then save the changes.

5.After this the web application is deployed and a URL is created that redirects to the web application.

6. After the deployment users can commit changes, pull request and collabrate to work togeather.
